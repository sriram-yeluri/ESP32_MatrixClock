# MD_Parola Max7219 Display Effects List

The following list contains the available display and animation effects (`textEffect_t`) in the **MD_Parola Library for Arduino**:

## Standard and Scrolling Effects
* `PA_PRINT`: Print text statically without animation.
* `PA_SCROLL_UP`: Scroll text vertically up.
* `PA_SCROLL_DOWN`: Scroll text vertically down.
* `PA_SCROLL_LEFT`: Scroll text horizontally from right to left.
* `PA_SCROLL_RIGHT`: Scroll text horizontally from left to right.
* `PA_SCROLL_UP_LEFT`: Scroll text diagonally up-left.
* `PA_SCROLL_UP_RIGHT`: Scroll text diagonally up-right.
* `PA_SCROLL_DOWN_LEFT`: Scroll text diagonally down-left.
* `PA_SCROLL_DOWN_RIGHT`: Scroll text diagonally down-right.

## Special Transition and Wipe Effects
* `PA_SLICE`: Slice text columns sequentially.
* `PA_MESH`: Mesh/matrix transition effect.
* `PA_FADE`: Fade text in or out.
* `PA_DISSOLVE`: Dissolve pixel effect.
* `PA_BLINDS`: Venetian blinds style transition.
* `PA_RANDOM`: Random pixel appearance.
* `PA_WIPE`: Wipe columns across the screen.
* `PA_WIPE_CURSOR`: Wipe effect with a visible leading cursor.
* `PA_SCAN_HORIZ`: Horizontal scanning line effect.
* `PA_SCAN_VERT`: Vertical scanning line effect.
* `PA_GROW_UP`: Grow text vertically from the bottom.
* `PA_GROW_DOWN`: Grow text vertically from the top.

## Opening, Closing and Sprite Effects
* `PA_OPENING`: Open outwards from the center.
* `PA_OPENING_CURSOR`: Open outwards with a cursor.
* `PA_CLOSING`: Close inwards toward the center.
* `PA_CLOSING_CURSOR`: Close inwards with a cursor.
* `PA_SPRITE`: User-defined graphical sprite animations.
* `PA_NO_EFFECT`: No change or instant update.
